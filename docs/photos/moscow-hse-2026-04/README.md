# Москва, НИУ ВШЭ · 1–3 апреля 2026

Первый этап команды в хакатоне «Движение по городу», в рамках IV Фестиваля робототехники ФКН НИУ ВШЭ.

## Состав команды

- Голышев Юрий Александрович — ROS 2-разработка и логика движения.
