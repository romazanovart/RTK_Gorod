# Движение по городу — Хакатон «Кубок РТК Высшая лига»

В данном репозитории представлено решение команды MISIS_robolab на Задание "Движение по городу" хакатона «Кубок РТК Высшая лига»

## 1. Краткое описание задания

Задание хакатона представляло собой соревнование, целью которого было предоставить робота, способного проехать по полигону, соблюдая правила дорожного движения (дорожная разметка и знаки-указатели) за отведенное время. Полигон представляет собой модель городского квартала с разметкой и знаками дорожного движения. Полигон состоит из 25 плотно соединенных квадратных ячеек, составленных в большой квадрат стороной в 5 ячеек (суммарный размер полигона 4x4 метра). Вокруг полигона установлен забор из секций, ограничивающих его.

Для решения задания оно было разбито на две ключевые задачи: распознавание знаков дорожного движения и движение робота по ячейкам

## 2. Робот команды - Роботизированная платформа Frob

![Логотип Frob](https://github.com/user-attachments/assets/4e6b15c5-6662-47f5-8419-bada88828910)

**Frob** - это недорогой мобильный робот с открытым исходным кодом, созданный для популяризации робототехники и обучения [ROS](https://www.ros.org/). Он предназначен для энтузиастов, студентов и преподавателей, изучающих мир робототехники. Независимо от того, являетесь ли вы начинающим или опытным разработчиком, Frob предоставляет универсальную платформу для решения широкого спектра задач обучения.

## 3. Основной функционал проекта

**Автономная навигация:** Движение по полигону (размером $4000\times4000$ мм) с использованием дорожной разметки и собственных карт.

**Соблюдение ПДД:** Распознавание и выполнение требований предписывающих («движение прямо/налево/направо») и запрещающих знаков («поворот запрещен»).

**Логика пассажирских перевозок:** Остановка на 2 секунды в зонах посадки (знак «Остановка»).

**Финальная остановка в зоне высадки** (знак «Парковка»).

**Обработка инфраструктуры:** Корректное прохождение Т-образных перекрестков и объезд опасных объектов.

## 4. Технологии и инструменты

**Языки:** Python / C++ 

**Библиотеки:** OpenCV (для распознавания знаков диаметром 100 мм и разметки шириной 40 мм).

**ROS2**

* **Навигация:** SLAM / Encoder-based odometry.
