# Фиксированный маршрут минского этапа

`move.py` перенесён из корня предоставленной папки без изменения команд. Он последовательно вызывает ROS 2-сервисы `/forward_robot` и `/rotate_robot` с заранее заданными расстояниями и углами.

Это отдельный сценарий фиксированного маршрута; он не обрабатывает камеру, знаки или лидар и не запускается автоматически городской миссией. При выполнении `python3 examples/minsk/move.py` робот сразу начнёт движение, если мост и контроллер уже запущены. Координаты и повороты рассчитаны на исходный полигон.

Для основного решения с обработкой знаков см. [инструкцию](../../docs/SOLUTION.md).
